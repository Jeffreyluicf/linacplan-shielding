LinacPlan v0.2.4 — GitHub Pages upload package

This is a separate application from RadPlan. Upload it to a new, separate
GitHub repository intended only for LinacPlan.

Upload these items to the repository root:
  1. index.html
  2. favicon.svg
  3. the complete assets folder (keep the folder name and both files inside)

Do not upload README_UPLOAD.txt unless you want these instructions to appear in
the repository.

After uploading, enable GitHub Pages under:
Settings > Pages > Deploy from a branch > main > /(root) > Save

Because index.html uses relative asset paths, the package works on a GitHub
project-page URL such as:
https://YOUR-USERNAME.github.io/YOUR-LINACPLAN-REPOSITORY/
